From zero to chatting

By the end of this page you'll have an AI agent running on your own computer and the Moch app on your phone, paired and talking. No accounts anywhere, and everything you install belongs to you.

You need: a computer you can leave on (a laptop is fine to start), a phone, and about half an hour.

1Put the agent on your computer

Moch is the remote control; the thinking happens in Hermes, a free, open-source agent that runs on your own machine. Installing it is one line in a terminal: 

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

On Windows, use PowerShell with iex (irm https://hermes-agent.nousresearch.com/install.ps1) instead. When it finishes, open a fresh terminal and run: 

hermes setup

hermes setup is a friendly wizard: it asks which AI provider you want to use (the companies behind the models; you'll need an API key from one of them) and checks that everything works. When it's done, you can already chat with your agent by running hermes.

New to this? An API key is a long password a model company gives you. You paste it in once and pay them directly for what you use. Hermes works with the usual providers; the wizard lists them.

2Turn on the gateway

Right now your agent only talks inside its own window. The gateway is the part that lets other things, like your phone, reach it: 

hermes gateway setup
hermes gateway start

Setup asks a couple of questions and hands out a session token: the house key other apps will use. Keep the gateway running (a terminal window is fine for tonight).

3Put Moch on your phone

Moch is young: it's not in the app stores yet, so tonight we run it the developer way. It takes three minutes and needs no coding:

  • On your phone, install Expo Go from the App Store or Play Store (a free helper app for running projects like this).
  • On the computer, download Moch and start it:
git clone https://github.com/SoftLand-Tech/Relay.git
cd Relay
npm install
npm start

A QR code appears in the terminal. Scan it with Expo Go and Moch opens on your phone. (You'll need Node.js installed for this part; the long-term-support version is fine.)

4Pair the two

One last command on the computer. It prints a QR code (or a link, if your terminal can't draw one) that tells Moch where your gateway lives and lets it in: 

./scripts/hermes-pair.sh --host 192.168.1.20 --port 8080

Use your own two numbers in place of the example: the address of the computer on your home network, and the port your gateway mentioned when it started in step 2. Then point Moch's camera at the QR code, and that's it. The app remembers this computer and reconnects to it on its own from now on. No camera handy? Tap More options in Moch and paste the link the script printed.

If it asks for a token: the first time you pair, the script may ask for your gateway's session token (its long name is the dashboard session token). That's the long key your gateway created when it was set up in step 2. Paste it when asked; it never gets typed on the phone.

5Use it away from home

On your own Wi-Fi this just works. To reach your agent from the office or the train, install Tailscale (a free, well-regarded tool that quietly connects your devices to each other over the internet) on both the computer and the phone. Then pair once more using the computer's Tailscale address with the --tls flag, and you have a second entry in Moch's computer list for the road.

If something doesn't work

  • Moch says it can't reach the computer: make sure the gateway is still running and both devices are on the same network (or Tailscale is on, on both).
  • The QR scan does nothing: use the script's printed link: in Moch tap More options and paste the hermes://connect… line.
  • Wrong port: the pairing command prints the address it's using; check it matches what your gateway said when it started.
