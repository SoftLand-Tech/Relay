Setup guide

Relay is client-only — before the app can chat, you need a self-hosted Hermes gateway you control (your own computer, a VPS, anything that stays on). Set one up with the upstream Hermes project, then come back here.

1 · Install and run

git clone https://github.com/SoftLand-Tech/Relay.git
cd Relay
npm install

npx expo start
# press w (web), a (Android), i (iOS) — or scan with Expo Go

Requirements: Node 22.x and npm. The project tracks Expo SDK 57 — if you plan to change code, read the versioned SDK 57 docs first; the SDK has changed substantially from earlier versions.

Without a gateway the app stops at the pairing screen — there is no demo mode. To exercise just the protocol layer offline, the repo ships node-runnable suites: npm run test, npm run test:slash.

2 · Pair with your gateway

On the machine running the gateway, print a QR (or a pairing link): 

./scripts/hermes-pair.sh --host <gateway-host> --port <gateway-port> --token <token>
# add --tls for wss (tailnet / public host)
  • The token is the gateway's dashboard session token; the script reads it from HERMES_DASHBOARD_SESSION_TOKEN and prompts if missing.
  • Point your phone at the QR in Relay's onboarding — or paste the hermes://connect?… link via More options.
  • The token is stored in the device keystore (SecureStore, with a web fallback), and the computer is remembered for one-tap reconnect.

3 · Reach it away from home

  • Same network: pair with the machine's LAN address over plain ws://.
  • Anywhere: install Tailscale (or your VPN of choice) on both machines and pair with the tailnet hostname + --tls. Works over mobile data, no port forwarding.
  • Pair the same machine twice — LAN and VPN — and switch between both entries from Settings → Computers.

4 · Optional: push for approvals

Local alerts work out of the box while the socket is alive. For notifications with the app closed, build with EAS (npx eas build), grab a push token in Settings, and run the repo's watcher on the gateway machine: 

./scripts/hermes-push-watch.sh \
  --host 127.0.0.1:<gateway-port> \
  --token <token> \
  --push-token 'ExponentPushToken[xxxx]'
