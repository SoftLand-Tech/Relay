SELF-HOSTED AGENT

Your agent,
in your pocket.

Relay is an open-source Expo (React Native) client for a self-hosted Hermes agent gateway. Streamed replies with live reasoning, approvals you can answer from your phone, scheduled automations — all talking to your server. The gateway holds the keys; Relay is the window.

Everything the gateway can do, from your phone

Nothing is hardcoded against a particular server — inventories of commands, skills and models are fetched from your gateway at runtime.

⚡Streaming + thinking

Answers stream token-by-token; reasoning arrives as collapsible Thinking blocks with elapsed time and ~tok/s. Markdown renders on completion, with copy and listen on every reply.

✅Answer from anywhere

Approvals, clarifications, sudo and secret requests arrive as interactive cards over the same socket — answer them from the grocery store, not just the desk.

💬Multi-session sidebar

Every conversation is an independent session. Search across all chats, pin / rename / archive / delete, grouped into Today, Yesterday and older.

🔗Multi-computer pairing

Pair your desk and your laptop: every gateway is remembered, Relay reconnects to the last one on launch, and tokens live in the device keystore — never in git.

⌘Slash commands & skills

Typing / drives off the gateway's own command registry, so new server-side commands and skills appear without an app update.

⏰Automations

Create, edit, pause and run cron jobs — every 30m, in 45m, every monday 9:00. Jobs run on the gateway, so they fire even when the app is closed.

How it works

Relay is client-only: no accounts, no cloud relay, no keys on your phone's vendor. You run the agent; the app pairs to it.

Run your gateway

Set up the open-source Hermes agent on your own machine — it holds the models, keys and sessions.

Pair by QR

scripts/hermes-pair.sh prints a QR (or a hermes://connect link). Scan it with Relay and the computer is remembered.

Chat from anywhere

On LAN over ws://, or away from home via Tailscale/VPN with wss://. Approvals can reach you through push even with the app closed.
